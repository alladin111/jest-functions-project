# jest-functions-project

Учебный проект по тестированию JavaScript-функций с использованием фреймворка Jest.

## Описание

Проект содержит реализацию четырёх простых математических функций и набор тестов к ним:

- `sum(a, b)` — возвращает сумму двух чисел;
- `multiply(a, b)` — возвращает произведение двух чисел;
- `divide(a, b)` — возвращает результат деления `a` на `b`; если `b = 0`, выбрасывает ошибку;
- `isEven(n)` — возвращает `true`, если число чётное, иначе `false`.

Тесты сгруппированы с помощью `describe` и покрывают позитивные и негативные сценарии для каждой функции.

## Требования

- Node.js версии 14 или выше;
- npm (устанавливается вместе с Node.js).

Проверить установленные версии:


node --version
npm --version

Установка
Клонируйте репозиторий:

git clone https://github.com/alladin111/jest-functions-project.git
cd jest-functions-project
Установите зависимости:


npm install
Команда установит Jest (он указан в devDependencies файла package.json).

Запуск тестов
Из корня проекта выполните:


npm test
Jest найдёт файл tests/mathFunctions.test.js, выполнит все 8 тестов и выведет отчёт.

Запуск тестов с анализом покрытия
Чтобы увидеть, какая часть кода покрыта тестами, выполните:


npm test -- --coverage
В консоли появится таблица с метриками покрытия (строки, ветви, функции), а в корне проекта будет создана папка coverage с HTML-отчётом. Откройте coverage/index.html в браузере для детального просмотра.

Используемые матчеры Jest
Матчер	Назначение
toBe()	Проверяет строгое равенство значений (для примитивов)
toThrow()	Проверяет, что функция выбрасывает исключение
